# DCA Signal (dca-signal)

> 미국 3배 레버리지 ETF 및 분할 적립식 자산(TQQQ, SOXL, UPRO 등) 대상 **정량 분할 적립식(DCA) 퀀트 시뮬레이터 및 사이클 분석 대시보드**입니다.

---

## 📌 주요 특징 및 기능

1. **정량 분할 적립(DCA) 시뮬레이션 엔진**:
   - **자유로운 분할 수 ($N$)**: 기본 40분할(10~80분할 지원, 1회 투입 배정액 자동 계산)
   - **전반부 / 후반부 분기점 ($M$회차) 커스터마이징**: 회차 기준 전환 (기본 20회차)
   - **전반부 룰**: 매일 1회분 기계적 정량 종가 매수
   - **후반부 룰 (방어 모드 & 평단가 기준선 조절)**:
     - **평단가 대비 $X\%$ 이하 시에만 매수** (슬라이더로 -15% ~ +5% 자유 조절, 기준 미달 시 매수 스킵/현금 보존)
     - 완충형 매수 (기준 이하 시 1회분 / 초과 시 0.5회분)
     - 단순 지속 매수 (조건 없이 매일 1회분)
   - **목표 익절률 ($+10\%$) 달성 시 전량 청산 및 사이클 1회차 자동 리셋**
   - **단리(원금 고정) vs 복리(수익금 재투자)** 모드 선택

2. **기간별 & 사이클별 다차원 성과 분석**:
   - **테스트 기간 선택**: 10년 / 5년 / 3년 / 1년 프리셋 및 **시작일~종료일 직접 입력(Date Picker)** 지원
   - **연도별 성과(Yearly Breakdown)**: 연도별 완료 사이클 수, 연간 실현 손익, 연간 수익률, 연간 최대 낙폭(MDD)
   - **사이클별 상세 기록(Cycle Timeline)**: 각 사이클의 시작일, 종료일, 소요 일수, 최대 소진 회차, 실현 손익
   - **리스크 지표**: CAGR(연평균 복리수익률), MDD, 최장 사이클 소요 기간
   - **벤치마크 비교**: 동일 자산의 Buy & Hold(단순 보유) 대비 자산 성장 곡선 비교

3. **고성능 클라이언트 사이드 UI**:
   - 깔끔하고 직관적인 화이트/슬레이트 라이트 테마 기반 대시보드
   - 파라미터 조절 시 **0.05초 만에 10년 치 시뮬레이션 실시간 재계산**
   - 차트(Equity Curve) 및 CSV 내보내기 지원

## 🚀 빠른 시작

### 1. 웹 시뮬레이터 실행
[index.html](index.html) 파일을 웹 브라우저(크롬, 엣지 등)로 바로 열거나 로컬 웹 서버로 열 수 있습니다:
```bash
python -m http.server 8080
```
웹 브라우저에서 `http://localhost:8080` 접속.

### 2. 터미널 백테스트 실행 (CLI)
```bash
python simulator.py
```

### 3. 최신 시세 데이터 업데이트 (Python)
```bash
python fetch_data.py
python build_presets.py
```
