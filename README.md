# DCA Signal (dca-signal)

> 미국 3배 레버리지 ETF 및 분할 적립식 자산(TQQQ, SOXL, UPRO 등) 대상 **라오어 무한매수법 & 정량 DCA 시뮬레이터 및 사이클 분석 대시보드**입니다.

---

## 📌 주요 특징 및 기능

1. **라오어 무한매수법 및 정량 분할(DCA) 시뮬레이션 엔진**:
   - **자유로운 분할 수 ($N$)**: 기본 40분할(20~100분할 지원)
   - **전반부 / 후반부 분기점 ($M$회차) 커스터마이징**: 회차 기준 전환 (기본 20회차)
   - **전반부 매수 룰**: 항상 종가 매수 / 평단가+5% LOC 매수 등
   - **후반부 매수 룰**: **종가 < 평단가 시에만 매수(하락장 현금 보존)** / 차등 분할 매수 / 지속 매수
   - **목표 익절률 ($+10\%$) 달성 시 전량 청산 및 사이클 1회차 자동 리셋**
   - **단리(원금 고정) vs 복리(수익금 재투자)** 모드 선택

2. **기간별 & 사이클별 다차원 성과 분석**:
   - **연도별 성과(Yearly Breakdown)**: 연도별 완료 사이클 수, 연간 실현 손익, 연간 수익률, 연간 최대 낙폭(MDD)
   - **사이클별 상세 기록(Cycle Timeline)**: 각 사이클의 시작일, 종료일, 소요 일수, 최대 소진 회차, 최종 수익률
   - **리스크 지표**: CAGR(연평균 복리수익률), MDD, 최장 고통 기간(Max Cycle Duration)
   - **벤치마크 비교**: 동일 자산의 Buy & Hold(존버) 대비 자산 곡선 비교

3. **고성능 클라이언트 사이드 UI**:
   - `stock-signal`의 프리미엄 다크/라이트 모드 트레이딩 디자인 시스템 계승
   - 슬라이더 및 옵션 변경 시 **0.05초 만에 10년 치 시뮬레이션 즉각 재계산**
   - 차트(Equity Curve & Drawdown) 및 인터랙티브 필터 제공

## 🚀 빠른 시작

### 1. 최신 시세 데이터 업데이트 (Python)
```bash
python fetch_data.py
```
> Yahoo Finance를 통해 TQQQ, SOXL, UPRO, QLD, QQQ, SPY, KODEX 레버리지(122630.KS)의 10년 일봉 데이터를 자동 수집하여 `data/`에 JSON 형태로 저장합니다.

### 2. 터미널 백테스트 실행 (CLI)
```bash
python simulator.py
```

### 3. 웹 시뮬레이터 실행
`index.html` 파일을 브라우저로 바로 열거나, 간단한 웹 서버로 구동할 수 있습니다:
```bash
# Python 내장 웹서버 실행 예시
python -m http.server 8080
```
웹 브라우저에서 `http://localhost:8080` 접속.
