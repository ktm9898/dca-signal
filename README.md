# DCA Signal (dca-signal)

> 미국 3배 레버리지 ETF 및 분할 적립식 자산(TQQQ, SOXL, UPRO 등) 대상 **정량 분할 적립식(DCA) 실전 대시보드 & 퀀트 시뮬레이터 시스템**입니다.

---

## 📌 주요 특징 및 구조

### 1. 실전 대시보드 (`index.html`)
- **실전 가동 현황**: 투자 시작일(D+일수) 및 현재 가동 중인 실전 전략(종목, 원금, 분할수, 전환점, 후반매수조건, 목표수익률, 단리/복리) 실시간 모니터링
- **오늘의 실시간 신호 (Live Signal Box)**:
  - 🟢 **전량 익절 매도**: 목표 수익률 달성 시 실현 수익 알림 및 익절 버튼 활성화
  - 🔵 **정량 매수**: 전반부 1회분 정량 매수 안내 (권장 수량 및 금액 계산)
  - 🟠 **조건부 매수**: 후반부 평단가 대비 조건 만족 시 저점 매수
  - ⚪ **매수 스킵 (관망)**: 후반부 조건 미달 시 현금 보존 관망
  - 🟣 **분할 소진 (대기)**: 전 분할 소진 시 반등 익절 대기
- **원클릭 기록 처리**:
  - `[오늘 매수 완료 (+1회차)]`: 클릭 시 회차/수량/평단가 자동 갱신 및 구글 시트 클라우드 실시간 기록
  - `[목표 달성! 전량 익절 완료]`: 목표 익절 시 수익금 확정 및 다음 사이클 1회차 자동 리셋
- **1줄 콤팩트 KPI**: 진행 회차(게이지), 투입 원금(잔여 현금), 보유 평단가, 평가 손익률, 목표 익절가, 누적 실현 손익
- **매매 일지 & 완료 사이클 이력 탭**

### 2. 퀀트 백테스트 & 데이터조회 (`backtest.html`)
- **군더더기 없는 모바일 최적화 클린 UI**: 괄호나 긴 부연설명을 없애고 간결한 핵심 단어 위주로 컴팩트하게 정리
- **백테스트 시뮬레이터**: 10년 / 5년 / 3년 / 1년 / 직접 입력 기간에 걸친 10년 치 시뮬레이션 0.05초 실시간 계산
- **단일 행 KPI 지표**: 최종 자산, CAGR, MDD, 완료 사이클, 평균 기간, 최장 사이클
- **[실전 적용] 원클릭 버튼**: 백테스트에서 검증한 최적의 파라미터를 실전 대시보드 전략으로 즉시 전환
- **구글 시트 슬롯 (1~10번)**: 연구한 전략을 클라우드 슬롯에 즉시 저장 및 불러오기
- **ETF 가격 데이터 조회 (Price Viewer)**: 30일/100일/1년/3년/전체 OHLCV 시세 테이블

### 3. 구글 스프레드시트 클라우드 연동 (`gas_code.js`)
- Google Apps Script 웹앱 API (`doGet`, `doPost`)를 통한 실시간 양방향 통신
- `DCA_Active_Strategy`: 현재 가동 중인 실전 전략 및 누적 매수 현황
- `DCA_Strategy_Slots`: 1~10번 전략 슬롯 프리셋 보관함
- `DCA_Trade_Journal`: 매매 일지 및 사이클 완료 기록

## 🚀 빠른 시작

### 1. 실전 대시보드 실행
```bash
python -m http.server 8080
```
웹 브라우저에서 `http://localhost:8080` (실전 대시보드) 또는 `http://localhost:8080/backtest.html` (백테스트) 접속.

### 2. 최신 시세 데이터 업데이트 (Python)
```bash
python fetch_data.py
python build_presets.py
```
